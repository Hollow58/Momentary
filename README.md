# Momentary
Momentary is een sociale app gemaakt met React Native en Expo. In de app kun je posten, vrienden toevoegen en chatten met gebruikers. Je kan ook je profiel bewerken en het trackt je Spotify wanneer je naar een nummer luistert.

De app heeft een PHP-backend die deployed is op een server. Gegevens zoals berichten, vrienden en gebruikers worden opgeslagen in phpMyAdmin.
